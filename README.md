# Eray Kostereli - Portfolio

This is the source code for my personal portfolio/CV website. I built it from scratch to showcase my projects, skills, and experience. The site supports both Turkish and English, and is fully responsive.

🔗 [eraykostereli.com](https://eraykostereli.com)

## Tech Stack

- **React + Vite** – for fast development and build process
- **Tailwind CSS** – for styling and responsive design
- **React Router** – for page navigation
- **react-i18next** – for Turkish/English language support

## Getting Started

To run the project locally:

```bash
cd eray-portfolio
cd eray-portfolio
npm install
npm run dev
```

After these steps, the project will be running at `http://localhost:5173`.
